# OSS.1.4.2 — Solicitud concreta de evidencia de activos

Este cuestionario mantiene la identidad visual actual y no autoriza ni ordena
reemplazar activos. Su objetivo es resolver procedencia, fuentes, términos y
permiso de redistribución antes de preparar una futura distribución OSS.

La declaración vigente del mantenedor continúa en **OPCIÓN 3**. No se solicita
nombre legal, RFC, domicilio, teléfono, correo privado ni documentación fiscal.
Una respuesta pública del mantenedor o un archivo fuente aportado al repositorio
es suficiente para continuar el expediente; no debe incluir prompts privados,
tokens ni identificadores de cuenta.

## A. Icono cuadrado

Rutas: `icono/icono.png` y `public/icono.png`.

1. ¿Quién creó materialmente el diseño y el archivo PNG?
2. ¿Se utilizó una imagen, plantilla, personaje, icono o diseño previo?
3. ¿Qué herramienta se utilizó y el archivo fue generado completamente o
   editado posteriormente?
4. ¿Se conserva el archivo fuente o un export original anterior al PNG?
5. ¿Se utilizó una cuenta personal o comercial para crear el activo?
6. ¿Se autoriza expresamente redistribuir este archivo en una futura entrega
   OSS y modificarlo?
7. ¿Se autoriza únicamente su uso en la identidad oficial de Lanzo-POS?
8. ¿Existe un diseñador o tercero que deba autorizarlo?

## B. Wordmark PNG

Ruta: `icono/icono-web.png`.

1. ¿Quién creó materialmente el wordmark PNG y cuál es su relación con el
   icono cuadrado?
2. ¿Se utilizó una imagen, plantilla, wordmark, tipografía o composición
   previa?
3. ¿Qué herramienta se utilizó y qué edición o exportación produjo el PNG?
4. ¿Se conserva el archivo fuente, una versión editable o el archivo original
   de 1024×1024?
5. ¿El texto y la tipografía fueron creados dentro de la herramienta o se
   incorporó un elemento externo?
6. ¿Se utilizó una cuenta personal o comercial?
7. ¿Se autoriza expresamente redistribuir y modificar este archivo fuera de la
   identidad oficial, o sólo usarlo como marca oficial?
8. ¿Existe un diseñador o tercero que deba autorizar el wordmark?

## C. Familia PWA

Rutas: `public/icono-web.png`, `public/pwa-192x192.png` y
`public/pwa-512x512.png`.

1. ¿Cuál es la fuente canónica de los tres PNG PWA?
2. ¿`public/icono-web.png` de 192×192 y `public/pwa-192x192.png` fueron
   copiados byte a byte de forma intencional?
3. ¿Qué herramienta, comando y parámetros produjeron la variante 512×512 y
   las variantes 192×192?
4. ¿Puede reproducirse exactamente el PNG 192×192 desde el 512×512, o el 512
   desde el 192×192, con una transformación determinista conocida?
5. ¿Se conserva la fuente o el archivo exportable original?
6. ¿Los tres derivados pueden redistribuirse y modificarse en una futura
   entrega OSS?
7. ¿Se autoriza únicamente su uso como iconos PWA de la identidad oficial?
8. ¿Existe un diseñador, proveedor o tercero que deba autorizar alguno de los
   derivados?

## D. Wordmark SVG

Ruta: `public/log.svg`.

1. ¿Quién creó materialmente este SVG y qué herramienta de IA o diseño se
   utilizó, si se recuerda?
2. ¿Se utilizó una imagen, plantilla, icono, wordmark o tipografía previa?
3. ¿El texto `LANZO` y la familia `sans-serif` fueron escogidos o editados
   manualmente después de la generación?
4. ¿Se conserva un prompt no privado, archivo fuente o historial de edición que
   pueda publicarse?
5. ¿Se utilizó una cuenta personal o comercial y se conocen sus términos
   históricos aplicables?
6. ¿Se autoriza expresamente redistribuir y modificar este SVG, o únicamente
   utilizarlo como identidad oficial?
7. ¿Existe un diseñador, proveedor o tercero que deba autorizarlo?

## E. Marca SVG

Ruta: `public/logIcon.svg`.

1. ¿Quién creó materialmente este SVG y cuál es su relación con `log.svg`, la
   familia PWA y el icono cuadrado?
2. ¿Es una conversión técnica, una recreación o una variante independiente?
3. ¿Se utilizó una imagen, plantilla, icono o forma previa de un tercero?
4. ¿Qué herramienta se utilizó y se conserva el archivo fuente o exportable?
5. ¿Se utilizó una cuenta personal o comercial y se conocen sus términos
   históricos?
6. ¿Se autoriza expresamente redistribuir y modificar el SVG, o únicamente
   usarlo como marca oficial?
7. ¿Existe un diseñador, proveedor o tercero que deba autorizarlo?

## F. Icono del asistente

Ruta: `public/boticon.svg`.

1. ¿Quién creó materialmente el boticon y cuál es la fuente exacta de la
   derivación declarada en sus comentarios?
2. ¿La fuente fue una ruta del repositorio, una imagen, una plantilla, un bot,
   personaje, icono o diseño externo?
3. ¿La derivación fue una conversión técnica o una recreación manual/mediante
   IA?
4. ¿Qué herramienta se utilizó, se conserva el archivo fuente y se utilizó una
   cuenta personal o comercial?
5. ¿Existe permiso explícito para derivar la fuente y para redistribuir y
   modificar este SVG?
6. ¿Se autoriza únicamente su uso como icono del asistente oficial de
   Lanzo-POS?
7. ¿Existe un diseñador, proveedor o tercero que deba autorizarlo?

## Criterio de cierre

La respuesta debe identificar la familia, el archivo o fuente aportado, la
relación con los activos actuales y el alcance exacto del permiso. Una
declaración de conservación o incorporación al repositorio, por sí sola, no
resuelve el grant de redistribución. Hasta recibir evidencia suficiente, las
seis familias permanecen `MAINTAINER EVIDENCE REQUIRED` y el estado global de
activos permanece `ASSET NO-GO / ASSET REVIEW REQUIRED`.
