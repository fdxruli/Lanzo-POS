`observe(promise)` joins a known, already-owned lifetime. It is not a factory
admission API or cancellation right. New tasks use `track(factory)`. A shared
revalidation record owns a dedicated instance of the same lifecycle helper;
consumers join its root+raw completion before execution. Quiescing a consumer
does not cancel someone else's transport or grant it ownership of continuations.
The original owner retains its persistence guard. A changed actor/session/tenant
never joins its record. A record initially created without a caller observer
conservatively retains `shared_license_revalidation_owner` UNKNOWN for a joining
consumer, even though the new internal ledger also observes its settlement.

The production preferences/Drive refresh functions are synchronous local reads.
Async replacements/callbacks stay UNKNOWN and their returned promises are
observed. This does not certify detached work hidden inside an arbitrary provider.
The audited profile provider advertises version 1; substitutes without that
contract retain the old profile UNKNOWN. Do not copy the property to an unaudited
provider or infer whole-app drain from this scoped assertion.

`_processServerValidation` root is observable but its store subscribers, license
sync timers/realtime, cloud pulls/outbox and automatic recovery remain UNKNOWN.
No listener/coordinator contract is rewritten here. No SYNC_QUIESCED or remote
confirmation follows from PROCESSING_SETTLED or registered CHILD_WORK_SETTLED.
Admin/offline preparation markers also remain conservative: their broader
DB/session/transition children do not expose a complete lifecycle in this phase.
