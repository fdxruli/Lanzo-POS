# LANZO POS — instrucciones para agentes

Antes de modificar la interfaz de **Configuración**, leer y respetar [docs/design/CONFIGURACION-UX.md](docs/design/CONFIGURACION-UX.md), fuente canónica para el diseño del módulo.

La guía no autoriza refactorizaciones masivas, cambios comerciales, permisos, SQL, publicación ni merge. Mantener el alcance mínimo, validaciones, persistencia y compatibilidad. Reportar por separado código, QA automatizado, QA manual y Production.
